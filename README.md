# QR Code Generator

A QR code generator app built with JavaScript.

## Getting Started

```bash
git clone https://github.com/devhubasmr/qr-code-generator.git
cd qr-code-generator
```

Then open `index.html` in your browser.

## Tech Stack

- HTML
- CSS
- JavaScript
